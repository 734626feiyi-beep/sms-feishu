# 短信自动转发到飞书（测试机专用）

一句话说明：**测试机收到短信 → 自动生成一张短信通知图片 → 自动发到指定的飞书群**，你和 20 位同事都能在群里看到、也能自行转发。

---

## 一、它是怎么工作的（先看这个，心里有数）

```
短信到达手机
   ↓
本 App 被系统唤醒（同时每 15 分钟还会核对一次收件箱兜底，防漏收）
   ↓
把短信内容画成一张「短信通知」图片（纯本地生成，不截屏）
   ↓
上传到飞书 → 发到你指定的群里（图片 + 可选文字版）
```

### 为什么不是"真的屏幕截图"？

Android 14 / HyperOS（澎湃 OS）上，App 在后台截屏必须用系统级录屏授权，**手机每次重启都要重新手动授权一次**，息屏、锁屏、某些界面还会截出黑屏，测试跑一夜第二天基本就废了。所以这里改成"把短信内容画成图片"：内容 **100% 完整准确**、样式清晰、永不断线，效果和截图一样能看能转发。

## 二、准备工作 A：在飞书建一个"机器人"（约 10 分钟，只需做一次）

> 为什么要建：飞书普通的"群机器人 Webhook"**只能发文字，发不了图片**。要发图片必须用"企业自建应用"。

1. 浏览器打开飞书开放平台 → <https://open.feishu.cn/app>
2. 点 **创建企业自建应用**，名字随便填（例如 `短信测试机`），创建。
3. 进入应用后，左侧 **凭证与基础信息**，把这两个值记下来（等会儿要填进 App）：
   - **App ID**（`cli_` 开头）
   - **App Secret**
4. 左侧 **添加应用能力** → 添加 **机器人**。
5. 左侧 **权限管理**，搜索并勾选开通这三个权限：
   - `im:message`（发送消息）— 也就是"以应用的身份发消息"
   - `im:resource`（上传图片/文件资源）
   - `im:chat:readonly`（获取群组信息，用于 App 里一键选群）
6. 左侧 **版本管理与发布** → **创建版本** → 提交发布（你是管理员就直接通过审批）。
7. 回到飞书客户端，**新建一个群**（例如"短信测试群"），把这个机器人 **拉进群里**。
   > 机器人不在群里，消息就发不进去，这一步最容易被漏掉。

## 三、准备工作 B：把这个源码变成 APK（不用装开发工具）

### 方式 1：GitHub 云端自动编译（推荐，你只需要浏览器）

1. 注册/登录 GitHub → 右上角 **+ → New repository** → 名字填 `sms-feishu` → **Create repository**（Private 也行）。
2. 把我给你的 `SmsFeishu` 文件夹 **整个拖进** 仓库页面（页面上有 "drag files here"）→ 点 **Commit changes**。
   > 注意：要拖 `SmsFeishu` 文件夹**里面的内容**（能看到 `app`、`.github` 那一层），不要多套一层文件夹。
   > 如果 `.github` 文件夹拖不上去，见下面"常见问题 6"。
3. 仓库顶部点 **Actions** → 左侧点 **构建 APK** → 右上 **Run workflow**（或直接等 push 触发的构建）。
4. 等 3～5 分钟变绿 ✅ → 点进这次运行 → 页面底部 **Artifacts** → 下载 **sms-feishu-apk**（是个 zip，解压后里面是 `app-debug.apk`）。

### 方式 2：本地 Android Studio（不想用 GitHub 时）

1. 装 Android Studio（免费），启动后 **Open** 选择 `SmsFeishu` 文件夹，等它自动同步。
2. 菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**，编译好的 APK 在 `app/build/outputs/apk/debug/`。

## 四、装到 Redmi Note 13R 上（5 分钟）

1. 把 `app-debug.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘都行），点击安装，允许"安装未知应用"。
2. 打开 App **短信转发飞书**，按界面从上到下走：
   - **第 1 步**：点"申请短信权限"，弹窗点 **允许**（两个权限都允许）。
   - **第 2 步**：填入飞书的 App ID、App Secret → 点 **保存**。
   - **第 3 步**：点 **一键获取群列表并选择** → 在弹窗里选你的"短信测试群"。
     （如果列表为空，看下面"常见问题 3"）
   - **第 4 步**：点 **发送一条测试短信到飞书** → 飞书群里应该马上出现一张图片。
3. 用真实短信验证：让同事或平台给你的测试号发一条测试短信，看群里是否自动出现。

### HyperOS（小米）必须再做的 5 个设置

不设置的话，息屏一会儿就收不到了：

1. **设置 → 应用设置 → 应用管理 → 短信转发飞书 → 权限管理**：短信权限设为 **允许**。
2. 同上页面 → **省电策略 → 无限制**。
3. 同上页面 → **自启动 → 允许**。
4. **最近任务列表**里找到本 App，长按/下拉把它 **加锁**（小锁图标）。
5. 通知权限允许（保持通知，方便发现异常）。

## 五、日常使用

- 换目标群：回到 App，第 3 步重新选一次即可。
- 只看不用的同事：直接拉进飞书群就行，不需要装 App。
- 想转发：群里长按图片 → 转发。
- 出问题：App 里最下方 **运行日志** 会写明每一步的结果（收到短信、发送成功、失败原因）。截图发我看即可。

## 六、常见问题

1. **群里没反应，日志显示"跳过：飞书配置不完整"** → 第 2 步 App ID / Secret 没保存，或第 3 步没选群。
2. **日志显示"获取 token 失败"** → App ID 或 App Secret 复制错了（注意前后空格）。
3. **点"获取群列表"提示没找到群** → 依次检查：应用是否已"创建版本并发布"；机器人是否已拉进群；`im:chat:readonly` 权限是否已开通。
4. **日志显示"发送消息失败 (code=230002)"** → 机器人不在这个群里，把它拉进去。
5. **某条短信没发出去** → 确认开着"兜底扫描"开关；HyperOS 那 5 个设置是否都做了；偶尔网络断会自动重试 3 次。
6. **`.github` 文件夹拖不进 GitHub** → 在仓库里点 **Add file → Create new file**，文件名填 `.github/workflows/build-apk.yml`，把工作流内容粘进去保存即可。
7. **用的是国际版飞书（Lark）** → 打开 `app/src/main/java/com/jiayan/smsfeishu/FeishuClient.kt`，把 `open.feishu.cn` 改成 `open.larksuite.com`。
8. **安全提醒**：App Secret 保存在手机里，相当于这个机器人账号的钥匙。建议专门建一个机器人只用于短信测试，不要把测试机随便借人。

## 七、代码结构（想改的时候看）

| 文件 | 作用 |
| --- | --- |
| `SmsReceiver.kt` | 收到短信时的入口（含长短信拼接） |
| `SmsPipeline.kt` | 去重 + 记日志 + 投递到上传队列 |
| `UploadWorker.kt` | 画图 → 上传 → 发到群，失败自动重试 |
| `SmsImageRenderer.kt` | 把短信画成「短信通知」图片 |
| `FeishuClient.kt` | 飞书接口（token / 上传图片 / 发消息 / 列群） |
| `SmsInboxWorker.kt` | 15 分钟一次的兜底扫描，防漏收 |
| `MainActivity.kt` | 配置界面 |
| `Prefs.kt` | 本地配置、日志、去重记录 |
